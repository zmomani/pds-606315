# Course project

Three stages, 30 marks total. All three must be submitted to qualify for project marks.

| Stage | Due | Deliverable | Marks | Template |
|---|---|---|---|---|
| 1 · Proposal & Data Foundation | end of Week 5 | 1–2 page proposal + working EDA notebook | 10 | `stage1_template.ipynb` |
| 2 · Data Collection & Processing | end of Week 9 | Notebook with parallel fetching, JSON/API integration, web-scraped enrichment, before/after quality stats | 10 | *coming* |
| 3 · Web App, Deployment & Presentation | Week 14 | Deployed Django app with dashboard + Scikit-learn endpoint; 6–8 page report; live demo | 10 | *coming* |

**Stage 1 grading:** clarity of proposal (3) · dataset appropriateness (3) · EDA notebook correctness & depth (4).

## How to submit Stage 1

1. Copy `stage1_template.ipynb` to `stage1_<team-name>.ipynb` and fill in every placeholder.
2. Put your dataset in `project/data/` if it is under 50 MB; otherwise add a `download.md` with the source and steps.
3. Run **Kernel → Restart and Run All** so every output is fresh, save, commit, push.
4. Submit the repository link on the LMS.
